      学习外汇交易时常用到两个工具，一个是MT4，一个是MT5。目前有大量的平台使用的MT4，比较稳定，资金迁移是一件麻烦的事，所以就放那里慢慢玩着。MT5的好处是可以用Python来操作，这样为广大编程爱好者开辟了一处胆量与智慧的试炼场。无数的理论、策略，都可以天马行空地在数字的海洋里放飞自我，一场数字游戏就这样开始了。

      很快，你将不得不面对一个事实，两类平台都有你喜欢的优点，该如何打通呢？跟单工具此刻就诞生了。我们需要的是Python端程序驱动MT5来做单，跟单程序通知MT4来开仓、平仓、修改订单。这样，大量的精力可以用来做策略、做研究，两个平台都能玩起来。

      那么现在，问题来了，这学习成本有点高啊。我试着在网上搜索免费的来玩玩，结果肯定是以失败而告终。为啥这么简单一个小玩意可以如此令人不开心？当然是不能屈服了，上了GitHub，找找代码试试。结果还真不错，有一个能用的。
